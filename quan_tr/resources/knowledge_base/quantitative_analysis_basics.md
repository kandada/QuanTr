# 量化分析基础知识

## 概述

量化分析是通过数学模型和计算机技术对金融市场进行分析和决策的方法。它将投资理念转化为可量化的指标和策略，通过历史数据验证策略的有效性。

## 核心概念

### 1. 阿尔法（Alpha）
- **定义**：投资组合相对于基准的超额收益
- **计算公式**：Alpha = 投资组合收益 - 无风险收益 - β × (市场收益 - 无风险收益)
- **意义**：衡量投资经理的选股能力

### 2. 贝塔（Beta）
- **定义**：投资组合相对于市场的系统性风险
- **计算公式**：β = Cov(投资组合收益, 市场收益) / Var(市场收益)
- **意义**：
  - β = 1：与市场波动一致
  - β > 1：比市场波动更大
  - β < 1：比市场波动更小

### 3. 夏普比率（Sharpe Ratio）
- **定义**：每单位风险获得的超额收益
- **计算公式**：Sharpe = (投资组合收益 - 无风险收益) / 投资组合标准差
- **意义**：衡量风险调整后的收益

### 4. 最大回撤（Maximum Drawdown）
- **定义**：投资组合从峰值到谷底的最大损失
- **计算公式**：MDD = (峰值 - 谷底) / 峰值
- **意义**：衡量投资组合的下行风险

## 分析方法

### 1. 基本面量化
#### 价值投资指标
- **市盈率（P/E）**：股价/每股收益
- **市净率（P/B）**：股价/每股净资产
- **市销率（P/S）**：市值/营业收入
- **股息率**：每股股息/股价

#### 成长性指标
- **营收增长率**：(本期营收 - 上期营收) / 上期营收
- **净利润增长率**：(本期净利润 - 上期净利润) / 上期净利润
- **ROE增长率**：净资产收益率的变化率

#### 财务健康指标
- **资产负债率**：总负债/总资产
- **流动比率**：流动资产/流动负债
- **速动比率**：(流动资产 - 存货)/流动负债

### 2. 技术面量化
#### 趋势指标
- **移动平均线（MA）**：
  - 短期MA（5日、10日、20日）
  - 长期MA（50日、100日、200日）
  - 金叉/死叉信号

- **MACD指标**：
  - DIF线：12日EMA - 26日EMA
  - DEA线：DIF的9日EMA
  - MACD柱：DIF - DEA

#### 动量指标
- **相对强弱指数（RSI）**：
  - 计算公式：RSI = 100 - 100/(1 + RS)
  - RS = 平均上涨幅度/平均下跌幅度
  - 超买线：70，超卖线：30

- **随机指标（KDJ）**：
  - K值：当前收盘价在N日内价格区间的相对位置
  - D值：K值的M日移动平均
  - J值：3×K - 2×D

#### 波动率指标
- **布林带（Bollinger Bands）**：
  - 中轨：N日移动平均线
  - 上轨：中轨 + k×标准差
  - 下轨：中轨 - k×标准差
  - 默认参数：N=20，k=2

- **平均真实波幅（ATR）**：
  - TR = max(当日最高-当日最低, abs(当日最高-前日收盘), abs(当日最低-前日收盘))
  - ATR = TR的N日移动平均

### 3. 市场情绪量化
#### 资金流向指标
- **主力资金净流入**：大单和中单净流入
- **北向资金**：沪股通+深股通资金
- **融资融券**：融资余额变化

#### 市场广度指标
- **上涨家数/下跌家数**：市场整体情绪
- **涨停板/跌停板数量**：市场极端情绪
- **成交量比率**：放量/缩量信号

## 量化策略类型

### 1. 多因子模型
#### 经典因子
- **价值因子**：低市盈率、低市净率
- **成长因子**：高营收增长、高利润增长
- **质量因子**：高ROE、低负债率
- **动量因子**：过去一段时间表现优异
- **规模因子**：小市值效应

#### 因子构建步骤
1. **因子选择**：基于经济逻辑选择因子
2. **因子处理**：标准化、去极值、中性化
3. **因子合成**：加权合成综合因子
4. **组合构建**：根据因子得分构建组合

### 2. 统计套利
#### 配对交易
- **原理**：寻找历史价格走势相关的两只股票
- **步骤**：
  1. 寻找相关性高的股票对
  2. 计算价差序列
  3. 设定入场和出场阈值
  4. 执行交易：做多低估股票，做空高估股票

#### 均值回归策略
- **原理**：价格围绕均值波动
- **应用**：
  - 布林带策略：价格触及下轨买入，触及上轨卖出
  - RSI策略：RSI超卖买入，超买卖出

### 3. 机器学习策略
#### 监督学习
- **分类问题**：预测涨跌方向
- **回归问题**：预测收益率
- **常用算法**：逻辑回归、随机森林、梯度提升树、神经网络

#### 无监督学习
- **聚类分析**：股票分类
- **降维技术**：PCA、t-SNE
- **异常检测**：发现异常交易模式

## 回测框架

### 1. 回测要素
#### 数据准备
- **价格数据**：开盘价、收盘价、最高价、最低价、成交量
- **财务数据**：资产负债表、利润表、现金流量表
- **因子数据**：各种量化因子

#### 交易规则
- **手续费**：佣金、印花税、过户费
- **滑点**：实际成交价与预期价的差异
- **交易限制**：涨跌停限制、T+1限制

#### 绩效评估
- **收益指标**：总收益、年化收益、胜率
- **风险指标**：波动率、最大回撤、VaR
- **风险调整收益**：夏普比率、索提诺比率、信息比率

### 2. 回测陷阱
#### 前视偏差（Look-ahead Bias）
- **问题**：使用未来信息进行决策
- **避免方法**：确保所有决策只使用历史信息

#### 幸存者偏差（Survivorship Bias）
- **问题**：只考虑现存股票，忽略已退市股票
- **避免方法**：使用全样本数据，包含退市股票

#### 过拟合（Overfitting）
- **问题**：模型在历史数据上表现好，但未来表现差
- **避免方法**：
  - 样本外测试
  - 交叉验证
  - 简化模型复杂度

## 风险管理

### 1. 风险类型
#### 市场风险
- **系统性风险**：影响整个市场的风险
- **非系统性风险**：特定公司或行业的风险

#### 流动性风险
- **市场流动性**：买卖价差、成交量
- **资金流动性**：资金周转问题

#### 操作风险
- **模型风险**：模型假设错误
- **执行风险**：交易执行问题
- **技术风险**：系统故障

### 2. 风险控制方法
#### 仓位管理
- **凯利公式**：f* = (bp - q) / b
  - f*：最优投资比例
  - b：赔率（盈利/亏损）
  - p：胜率
  - q：败率（1-p）

- **固定比例法**：每次投资固定比例资金
- **波动率调整**：根据市场波动调整仓位

#### 止损策略
- **固定比例止损**：亏损达到一定比例时止损
- **移动止损**：随着盈利增加提高止损位
- **时间止损**：持有时间超过一定期限止损

#### 分散化
- **资产分散**：投资不同资产类别
- **策略分散**：使用多个不相关策略
- **时间分散**：分批建仓

## 实践建议

### 1. 策略开发流程
1. **想法产生**：基于经济逻辑或数据挖掘
2. **数据收集**：获取高质量历史数据
3. **策略实现**：编写交易规则
4. **回测验证**：历史数据测试
5. **参数优化**：寻找最优参数
6. **样本外测试**：验证策略稳健性
7. **实盘测试**：小资金实盘验证
8. **监控调整**：持续监控和优化

### 2. 常见错误
- **过度优化**：参数过于复杂
- **忽略交易成本**：低估手续费和滑点影响
- **数据质量问题**：使用错误或不完整数据
- **心理偏差**：让情绪影响决策

### 3. 持续学习
- **关注学术研究**：阅读金融学术论文
- **参加行业会议**：了解最新技术和方法
- **开源社区**：参与量化开源项目
- **实践总结**：记录和分析交易经验
